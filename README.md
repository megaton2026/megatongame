# MEGATON — гра для корпоративного Telegram-каналу

Проста аркадна гра-ловилка «Злови деталь!»: гравець рухає колектор внизу екрана,
ловить фірмові деталі МЕГАТОН (+10 очок, золота деталь — +50) і уникає протікань
(втрата життя). Три життя, швидкість зростає з часом, є рекорд (зберігається в
браузері) і кнопка «Поділитись результатом».

Це один самодостатній файл `index.html` — без збірки, без залежностей,
працює офлайн просто у браузері.

## Про логотип

Сайт `mega-ton.com.ua` був недоступний із середовища розробки (заблокований
мережевою політикою), тому оригінальний файл логотипу звідти не завантажувався.
Натомість фірмовий знак (три хвилі) та написання перевідтворені у SVG на основі
наданого Brand Guideline Book: колір `#E53131` (PANTONE 179C), допоміжні
`#6C6E6B` та `#B72221`, пропорції знаку. Це стилізована реконструкція, а не
експорт офіційного векторного файлу.

**Якщо є оригінальні `.ai`/`.svg`/`.eps` файли логотипу** — просто заміните
хвилі в `index.html` (пошук `waveIconPath` та розмітку `<svg>` на екранах
старту/завершення) та в `assets/logo.svg` на офіційну векторну графіку.

## Як перевірити локально

Відкрийте `index.html` у браузері (подвійний клік або `open index.html`).
Керування: перетягування пальцем/мишкою по екрану, або стрілки ← → на
десктопі.

## Як викласти в Telegram-канал

Найпростіший варіант — захостити сторінку і кинути посилання в канал:
воно відкриється у вбудованому браузері Telegram прямо на телефоні.

1. **GitHub Pages** (найшвидше, безкоштовно):
   - Settings → Pages → Source: `main` / `/ (root)` у цьому репозиторії.
   - Гра буде доступна за адресою на кшталт
     `https://<org>.github.io/megatongame/`.
   - Опублікуйте це посилання постом у корпоративний канал.

2. **Telegram Mini App через бота** (глибша інтеграція, гра відкривається
   як повноцінний Web App усередині Telegram, з кнопкою під повідомленням):
   - Створіть бота через [@BotFather](https://t.me/BotFather) (`/newbot`),
     або використайте наявного корпоративного бота.
   - `/newapp` у BotFather → вкажіть URL захощеної сторінки (крок 1).
   - Додайте боту право писати в канал, і публікуйте пости з
     inline-кнопкою `web_app`, що відкриває гру.
   - У грі вже підключено `Telegram.WebApp` SDK (кнопка «Поділитись
     результатом» використовує `switchInlineQuery`, якщо доступно).

3. **Telegram Bot Games API** (класичний формат `/game`) — складніший
   варіант, потребує `sendGame` і `answerCallbackQuery` на бекенді бота;
   доцільний лише якщо потрібен саме нативний ігровий формат зі списком
   лідерів через Bot API.

Для каналу без бота варіант 1 — найпростіший і достатній.
