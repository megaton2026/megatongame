# MEGATON — гра для корпоративного Telegram-каналу

Проста аркадна гра-ловилка «Злови деталь!»: гравець рухає колектор теплої
підлоги внизу екрана, ловить шарові крани (+10 очок) і фітинги для
металопластикової труби (+50, рідше) та уникає протікань (втрата життя). Три
життя, швидкість зростає з часом, є особистий рекорд (зберігається в браузері),
загальний лічильник запусків гри та кнопка «Поділитись результатом».

Це один самодостатній файл `index.html` — без збірки, без залежностей,
працює офлайн просто у браузері.

## Про логотип

Сайт `mega-ton.com.ua` був недоступний із середовища розробки (заблокований
мережевою політикою), тому оригінальний файл логотипу звідти не завантажувався.
Натомість фірмовий знак (три хвилі) та написання перевідтворені у SVG на основі
наданого Brand Guideline Book: колір `#E53131` (PANTONE 179C), допоміжні
`#6C6E6B` та `#B72221`, пропорції знаку. Це стилізована реконструкція, а не
експорт офіційного векторного файлу.

**Якщо є оригінальні `.ai`/`.svg`/`.eps` файли логотипу** — просто заміните
хвилі в `index.html` (розмітку `<svg>` на екранах старту/завершення) та в
`assets/logo.svg` на офіційну векторну графіку. Падаючі деталі (кран/фітинг)
та колектор намальовані прямо в canvas у функціях `drawValve`, `drawFitting`,
`drawLeak` і `drawPlayer` — якщо форма чи колір не збігаються з реальною
продукцією, там же їх і можна підправити.

## Як перевірити локально

Відкрийте `index.html` у браузері (подвійний клік або `open index.html`).
Керування: перетягування пальцем/мишкою по екрану, або стрілки ← → на
десктопі.

## Як викласти в Telegram-канал

Найпростіший варіант — захостити сторінку і кинути посилання в канал:
воно відкриється у вбудованому браузері Telegram прямо на телефоні.

1. **GitHub Pages** (найшвидше, безкоштовно):
   - Settings → Pages → Source: `main` / `/ (root)` у цьому репозиторії.
   - Гра буде доступна за адресою на кшталт
     `https://<org>.github.io/megatongame/`.
   - Опублікуйте це посилання постом у корпоративний канал.

2. **Telegram Mini App через бота** (глибша інтеграція, гра відкривається
   як повноцінний Web App усередині Telegram, з кнопкою під повідомленням):
   - Створіть бота через [@BotFather](https://t.me/BotFather) (`/newbot`),
     або використайте наявного корпоративного бота.
   - `/newapp` у BotFather → вкажіть URL захощеної сторінки (крок 1).
   - Додайте боту право писати в канал, і публікуйте пости з
     inline-кнопкою `web_app`, що відкриває гру.
   - У грі вже підключено `Telegram.WebApp` SDK (кнопка «Поділитись
     результатом» використовує `switchInlineQuery`, якщо доступно).

3. **Telegram Bot Games API** (класичний формат `/game`) — складніший
   варіант, потребує `sendGame` і `answerCallbackQuery` на бекенді бота;
   доцільний лише якщо потрібен саме нативний ігровий формат зі списком
   лідерів через Bot API.

Для каналу без бота варіант 1 — найпростіший і достатній.

## Скільки разів зіграли

Внизу екрана (на всіх трьох екранах гри) показується напис «Зіграно ігор: N».
Це загальний лічильник для всіх, хто відкриє посилання — не персональний
рекорд конкретного гравця.

Технічно це виклик безкоштовного публічного лічильника
[countapi.mileshilliard.com](https://countapi.mileshilliard.com/) без
реєстрації та без власного бекенду: гра відправляє `GET`-запит на унікальний
ключ `megaton_com_ua_floorheating_catch_game_plays_v1` при кожному натисканні
«Почати гру» (`bumpPlayCount()` в `index.html`), і поточне значення
показується прямо в грі — окремо нікуди заходити не треба.

Важливо розуміти обмеження такого підходу:
- **Сторонній сервіс.** Дані (лише число запусків, без жодної особистої
  інформації) йдуть на зовнішній публічний API, а не на власний сервер
  компанії. Якщо потрібна повна конфіденційність/контроль — варіант із
  Google Analytics (GA4) надійніший, там дані належать вашому акаунту.
- **Без захисту від накрутки.** Будь-хто, хто знає ключ (він у відкритому
  вигляді в коді `index.html`), теоретично може штучно збільшити число.
  Для внутрішньої корпоративної гри це не критично.
- **Мережеві обмеження всередині цього середовища розробки не дозволили
  протестувати сам запит наскрізь** (пісочниця блокує вихід на сторонні
  домени за замовчуванням) — перевірено лише, що код коректно і без помилок
  вимикається, якщо запит не пройшов. У звичайному браузері користувача
  (не в цьому середовищі) запит піде як звичайний `fetch` до публічного API
  і має спрацювати без додаткових налаштувань. Перевірте лічильник одразу
  після викладення на GitHub Pages, зігравши пару разів.
